# Workspace Rules for PunFiction - 1-Star Travel Reviews Isolation

To prevent accidental changes to the Box Office Blunders codebases, please adhere to the following rules:

- **Primary Focus**: All modifications, features, and assets in this workspace must be limited to the `travelreviews/` subdirectory.
- **Do Not Modify Root Files**: Never modify files in the root folder that belong to Box Office Blunders (such as root `index.html`, root `style.css`, root `app.js`, `about.html`, `how-to-play.html`, or `boxofficeblunders/`).
- **Shared Backend Precaution**: If changes are required in `backend/` (such as unified server or daily challenge data files), ensure they only affect 1-Star Travel Reviews endpoints or 1-Star Travel Reviews JSON data, leaving the Box Office Blunders functionality entirely intact.
